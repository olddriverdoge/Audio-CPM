设置

网页内播放由后端流式提供音频，进度/暂停/音量都在页面内控制，不会拉起外部 App。 只有切到「系统播放器」模式或点播放条上的 ↗ 才会拉起 App。

存储源（本地 / WebDAV）

WebDAV 支持浏览 / 播放 / 元数据 / 下载（后续）与远端内部移动、删除、新建目录； 跨源搬运不做，文件处理只作用于本地。

界面配置（存本地 JSON）

视图 / 排序 / 分栏比例 / 目标目录标签 / 列设置 / 播放器设置等改动会自动写入上面的 JSON 文件， 换浏览器或清缓存后打开页面自动恢复。

列表表头

预设与自定义列都可勾选 / 取消，顺序随勾选与表头拖动；自定义列取消勾选只是隐藏，点 ✕ 才彻底删除。
